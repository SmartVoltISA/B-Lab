# B-Lab — Axioms / Phase 0

## Axiom B0

> Существуют два различимых состояния: `0` и `1`.

Это единственная исходная опора первой фазы.

## What is deliberately NOT defined

`0` и `1` не означают заранее:

- true / false;
- good / bad;
- absence / presence;
- positive / negative;
- low / high;
- any physical quantity.

Meaning may be assigned later by an explicit experiment or formal model.

## Phase 0 restrictions

1. No third symbol.
2. No automatic import of `-1 / 0 / +1` from Ω-Lab.
3. No hidden semantic assumptions.
4. No result is accepted because it was expected.
5. Every conclusion requires an archived experiment.

## Research question

What structures can arise from binary distinction alone when transitions, memory and relations are introduced step by step?
