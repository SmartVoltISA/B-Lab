# EXP-0022 — Emergent Loop Without Pre-Existing Fallback Route

## Status

**PASS — under the preregistered toy rule, a system starting from a pure directed chain can generate a reverse relation, form a cycle, and use the resulting relational history to change a later probe response to the same visible state.**

## Purpose

EXP-0021 showed that an emergent cycle plus independent persistent probe memory can alter later behavior. However, the initial topology still contained a pre-existing fallback edge:

```
A → B → C → D
A → D
```

EXP-0022 removes that fallback route.

The test asks whether the mechanism can create its own closed relational route from an initially acyclic chain.

## Initial topology

```
A → B → C → D
```

No cycle and no alternative route are present initially.

## Fixed rules

Structural memory:

```
m_struct(t+1) = 0.9*m_struct(t)
```

For the traversed relation:

```
m_struct(t+1) = min(1, 0.9*m_struct(t) + 0.6)
```

When structural memory of the traversed relation reaches 0.5, its reverse relation is added with probability 0.35 if absent.

Independent probe memory uses the same decay/reinforcement law, but **does not participate in topology changes**.

Autonomous policy:

- A follows A→B if present;
- at B, the system returns B→A if that relation has emerged; otherwise it follows B→C;
- C follows C→D;
- D stops because no forward edge is available.

At the final probe, the visible state is externally set to A in every matched run.

The probe reads a relation that can only have been created by the dynamic mechanism:

```
B if probe_memory(B→A) >= 0.5
STOP otherwise
```

Thus the probe asks whether the system's prior self-generated return path left an independently stored relational trace.

## Conditions

### A — dynamic topology + persistent probe memory

Reverse-relation plasticity enabled. Probe memory persistent.

### B — frozen topology + persistent probe memory

No structural plasticity. Probe memory persistent.

### C — dynamic topology + no probe memory

Structural plasticity enabled. Probe memory disabled/reset.

### D — frozen topology + no probe memory

Both mechanisms disabled.

## Results

1000 deterministic seeds per condition.

| Condition | Emergent A↔B cycle | Final probe = B |
|---|---:|---:|
| A — dynamic + persistent memory | **358/1000 = 35.8%** | **358/1000 = 35.8%** |
| B — frozen + persistent memory | **0/1000 = 0%** | **0/1000 = 0%** |
| C — dynamic + no probe memory | **358/1000 = 35.8%** | **0/1000 = 0%** |
| D — frozen + no probe memory | **0/1000 = 0%** | **0/1000 = 0%** |

The 35.8% cycle rate is the observed result of the fixed 0.35 reverse-edge creation probability across 1000 deterministic seeds.

## Main result

Removing the pre-existing A→D fallback route does **not** eliminate the mechanism.

The chain:

```
A → B → C → D
```

can generate:

```
A → B
↑   ↓
└───┘
```

when B→A is created.

That newly created reverse relation changes the trajectory from:

```
A → B → C → D → stop
```

to:

```
A → B → A → B → ...
```

until the probe time.

The independent probe memory records B→A. At the final externally imposed state A, the probe therefore receives a different relational history despite identical visible state.

## Critical controls

### Structural plasticity without probe memory

The cycle still forms in 358/1000 runs, proving that the cycle effect does not depend on the probe memory.

But the final probe never changes:

```
0/1000
```

Therefore cycle formation alone is insufficient for the measured read-back effect.

### Probe memory without structural plasticity

The chain never creates B→A:

```
0/1000
```

Consequently the probe has no B→A history to read.

This separates the two mechanisms.

## Causal chain supported by this experiment

```
initially acyclic relation structure
        ↓
persistent structural state
        ↓
structural plasticity
        ↓
new reverse relation
        ↓
emergent directed cycle
        ↓
additional self-generated traversal
        ↓
independent persistent relational memory
        ↓
same final visible state A
        ↓
different probe response
```

## What this establishes

Within this toy model:

- the fallback route A→D is not required;
- a cycle can arise from a purely acyclic chain through structural plasticity;
- the newly generated relation can feed back into the system's own trajectory;
- the resulting additional traversal can be stored independently;
- that stored relational history can alter a later response at the same externally imposed visible state.

This is a cleaner demonstration than EXP-0021 because the alternative return route is itself generated by the system rather than supplied in the initial topology.

## What this does NOT establish

It does not establish:

- consciousness;
- subjective experience;
- free will;
- intelligence;
- semantic understanding;
- universality of the mechanism;
- that cycles are necessary for memory;
- that the mechanism corresponds directly to biological nervous systems.

## Model dependence

The numerical 35.8% is specific to:

- 1000 deterministic seeds;
- reverse-edge probability 0.35;
- structural decay 0.9;
- reinforcement 0.6;
- the fixed A/B/C/D policy;
- the chosen probe threshold;
- the fixed probe time.

The result should therefore be interpreted as a reproducible property of this toy model, not as a universal constant.

## Conclusion

EXP-0022 closes the remaining structural loophole in EXP-0021:

**the system does not need a pre-installed alternative route.**

An initially acyclic chain can generate its own return relation; the return relation creates a cycle; the cycle generates additional traversal; independent relational memory preserves that history; and the preserved history changes the response to the same final visible state.

The supported mechanism is therefore:

**structure → plasticity → self-generated recurrence → relational memory → history-dependent read-back.**

## Next test

A natural next control is to vary the reverse-edge probability and independently vary memory persistence, then test whether cycle formation and read-back separate into two measurable response curves rather than moving together because both use the same fixed threshold.
