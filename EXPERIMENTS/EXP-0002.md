# EXP-0002 — Binary cycle and memory

Date: 2026-08-15
Status: protocol defined

## Question

Can a binary system represent a repeated transition cycle and distinguish a new cycle from a simple repetition of the same observed result?

## Constraint

Only `0` and `1` are permitted. No ternary state and no predefined semantic meaning for either value.

## Input sequences

### A

`0 → 1 → 0 → 1 → 0 → 1`

### B

`1 → 0 → 1 → 0 → 1 → 0`

### C

`0 → 1 → 1 → 0 → 0 → 1 → 1 → 0`

## Measurements

Record at minimum:

- number of states;
- number of transitions;
- unique directed transitions;
- repeated transitions;
- self-loops;
- cycle length where detectable;
- number of observed cycles;
- whether the same cycle is repeated;
- short-term history required to distinguish the current position in the cycle.

## Hypothesis

A finite-memory observer can detect that a transition has returned to a previously observed local state without requiring a third symbol.

This experiment does **not** assume that such memory is fundamental. It only tests whether the defined observer can detect recurrence.

## Required outcome classes

`NO_CYCLE / CYCLE_DETECTED / REPEATED_CYCLE / AMBIGUOUS`

## Anti-loop condition

The observer must not treat an indefinitely repeated identical output as indefinite progress. If the observed state/history returns to an already known configuration, it must record recurrence and allow a higher-level policy to choose whether to continue, alter the approach, or stop.

## Comparator handoff

The measured transition relation is passed to the Comparator without semantic labels. The Comparator may compare it with formal binary relations and graph representations.

## Rule

No result is accepted merely because it matches the hypothesis. A mismatch is preserved as a valid experimental result.
