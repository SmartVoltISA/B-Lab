# EXP-0007 — Can temporal memory be compressed?

## Question

Can the full observation index `t` be replaced by a smaller temporal representation while preserving enough information to distinguish histories?

## Candidate compression

For a contiguous binary sequence, the next source state is the previous target. Therefore an event can potentially be represented by the ordered target stream plus the initial state, rather than storing `(t, source, target)` for every event.

Example:

`0 → 1 → 0 → 1 → 0`

Full record:

`[(0,0,1),(1,1,0),(2,0,1),(3,1,0)]`

Candidate compressed representation:

`initial = 0`
`targets = [1,0,1,0]`

## Required tests

1. Reconstruct the original sequence from `(initial, targets)`.
2. Confirm different histories remain distinguishable.
3. Confirm `0→0` remains explicit.
4. Reject malformed/discontinuous representations.
5. Compare storage size conceptually; do not claim information-theoretic minimality yet.

## Boundary

This tests a specific compression scheme. Success means the representation is sufficient for the tested contiguous histories, not that it is globally minimal.
