# EXP-0001 — Minimal Binary Transitions

Status: protocol defined; execution pending

## Objective

Determine the minimal transition structures obtainable from two states without assigning semantic meaning to `0` and `1`.

## Inputs

State set:

`S = {0, 1}`

Initial transition candidates:

```text
0 → 0
0 → 1
1 → 0
1 → 1
```

## Measurements

Record:

- distinct states;
- distinct directed relations;
- reachable states;
- self-loops;
- cycle length;
- strongly connected components, if applicable;
- adjacency matrix.

## Comparison

After the experimental result is frozen, compare it with independently registered formal representations of a two-state directed relation/transition system.

## Expected output

No expected structural conclusion is assumed in advance. The experiment must report what is actually observed.

## Archive rule

Once executed, the result is stored separately from this protocol. Corrections create a new version rather than silently changing the historical result.
