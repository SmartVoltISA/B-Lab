# EXP-0003 — Representation invariance

## Question

Does the same binary structure remain unchanged when represented as:

1. observed sequence;
2. binary relation;
3. adjacency matrix;
4. directed edges / graph;

with special protection for state `0`?

## Test cases

- `0 → 1 → 0`
- `0 → 0`
- `1 → 1`

## Acceptance criterion

A representation round-trip passes only when the final relation is exactly equal to the relation derived from the original sequence.

The test must also distinguish the self-loop `(0,0)` from `(1,1)`.

## Interpretation

A successful result means only that the implemented representations preserve the tested binary relation. It does not establish a deeper mathematical or physical equivalence.
