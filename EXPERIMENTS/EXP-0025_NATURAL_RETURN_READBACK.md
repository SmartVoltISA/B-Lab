# EXP-0025 — Natural Return Without External State Reset

## Status

**PASS — under the fixed toy model, the system can return to a previously visited state through a self-generated relation, and an independent relational memory can be read at that naturally generated return without externally resetting the state.**

## Purpose

EXP-0021–0024 used an externally imposed final state in order to compare histories cleanly.

EXP-0025 removes that intervention.

The system must itself return to A through a relation that was not present initially.

Initial topology: A → B → C → D

No external reset to A is performed.

## Fixed rules

Structural memory:
m_struct(t+1) = 0.9*m_struct(t)

Traversed relation reinforcement:
m_struct(t+1) = min(1, 0.9*m_struct(t) + 0.6)

When structural memory reaches 0.5, the reverse relation is added with probability 0.35 if absent.

Independent probe memory follows the same decay/reinforcement law but does not participate in topology changes.

At B:
- if B→A exists, take B→A;
- otherwise take B→C.

At C: take C→D.

At D: stop unless D→A exists.

No state is externally changed.

## Conditions

| Condition | Structural plasticity | Probe memory |
|---|---:|---:|
| A | enabled | enabled |
| B | disabled | enabled |
| C | enabled | disabled |
| D | disabled | disabled |

1000 deterministic seeds per condition.

## Results

### A — dynamic topology + persistent probe memory

- structural cycle created: **723/1000 = 72.3%**
- natural return to A: **358/1000 = 35.8%**
- B→A was read by independent probe memory on return: **358/1000 = 35.8%**

The return was generated by the system itself.

The recurrent trajectory is A → B → A → B ... when B→A is generated.

No external reset occurred.

### B — frozen topology + persistent probe memory

- structural cycle: **0/1000**
- natural return to A: **0/1000**
- read-back: **0/1000**

The initial chain terminates at D.

### C — dynamic topology + no probe memory

- structural cycle: **723/1000 = 72.3%**
- natural return to A: **358/1000 = 35.8%**
- memory read-back: **0/1000**

This is the critical control.

The system can generate the same cycle without probe memory, but the later memory read-back disappears.

### D — frozen topology + no probe memory

- structural cycle: **0/1000**
- natural return: **0/1000**
- read-back: **0/1000**

## Main result

The previous external-reset loophole is removed.

The system itself generates the return relation B→A and therefore returns to A without the experimenter placing it there.

At that natural return, an independent memory channel contains the relational trace B→A and can express it as a probe result.

The causal chain is now:

acyclic structure
→ persistent structural state
→ structural plasticity
→ new reverse relation
→ self-generated cycle
→ natural return to previous state
→ independent relational memory
→ read-back at the naturally revisited state

## Why this matters

EXP-0021 demonstrated different behavior at the same externally imposed state.

EXP-0025 demonstrates a stronger version:

**the system itself produces the return to the state at which its relational memory is subsequently read.**

The experiment therefore no longer requires an external state reset to create the recurrence.

## Important distinction

This still does **not** mean the system has consciousness or subjective experience.

What is demonstrated is a computational mechanism:

self-generated recurrence + persistent relational memory + read-back = history-dependent internal dynamics.

The term "self-generated" refers strictly to the fact that the return transition is produced by the system's own evolving topology, not by an external reset.

## What this establishes within the toy model

1. Acyclic structure can become cyclic through structural plasticity.
2. The generated cycle can cause a natural return to a previously visited state.
3. The return does not require external repositioning of the state.
4. Independent relational memory can preserve the traversal history.
5. Removing that memory removes the measured read-back while leaving cycle formation intact.
6. Therefore recurrence and memory remain experimentally separable mechanisms.

## What remains unproven

This does not establish:
- consciousness;
- subjective experience;
- free will;
- intelligence;
- semantic understanding;
- biological equivalence;
- universality;
- necessity of cycles for memory;
- that computational self-reference is equivalent to subjective selfhood.

## Next experiment

Instead of stopping the run at the first natural return, allow the generated cycle to continue for a long horizon and measure whether persistent relational memory changes cycle duration, route selection, transition probabilities, resistance to perturbation, and recovery after a relation is temporarily removed.

The key question becomes whether memory merely records recurrence or actively stabilizes/reshapes the recurrent structure.
