# EXP-0006 — Temporal memory sufficiency

## Question

Is the minimal temporal record `(t, source, target)` sufficient to reconstruct the observed binary sequence, without expanding the binary state space?

## Baseline

EXP-0004 established that structural relation can lose temporal order and repetition. EXP-0005 introduced an observation index `t` as a separate history-layer coordinate.

## Test

For each valid sequence:

1. create the temporal record `(t, source, target)`;
2. reconstruct the sequence from the first source and ordered targets;
3. compare the reconstruction with the original sequence;
4. explicitly include `0→0` and alternating cycles.

## Required invariants

- state space remains exactly `{0,1}`;
- `t` is metadata/history, not a third state;
- `0→0` remains distinguishable;
- a successful round-trip establishes representational sufficiency for the tested sequences only.

## Boundary

This experiment does not claim that temporal records are the minimal possible memory in an information-theoretic sense. It tests whether this particular representation is sufficient. Reduction of the memory representation is a later experiment.
