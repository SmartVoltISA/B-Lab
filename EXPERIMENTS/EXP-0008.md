# EXP-0008 — Source-state reconstruction

## Question

Can the source state of each transition be omitted from temporal memory and reconstructed from the initial state plus the ordered target stream?

## Hypothesis

For a contiguous sequence, after the initial state is known, each next source is exactly the previous target. Therefore `(initial, targets)` should be sufficient to reconstruct every `(source, target)` event.

## Control

`0 → 1 → 0 → 1 → 0`

Stored:

`initial = 0`
`targets = [1,0,1,0]`

Reconstructed transitions:

`(0,1), (1,0), (0,1), (1,0)`

## Required tests

- reconstruction for both initial states;
- explicit `0→0` self-loop;
- repeated transitions;
- rejection of non-binary values;
- confirmation that the reconstructed transition history exactly matches the original.

## Boundary

This is a sufficiency test for contiguous binary histories. It does not establish global information-theoretic minimality.
