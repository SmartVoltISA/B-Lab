# EXP-0005 — Minimal temporal memory

## Question

What is the minimum additional information required to distinguish histories that induce the same structural relation?

## Baseline

A binary relation records which transitions occurred:

`R = {(source, target)}`

This preserves structural connectivity but can discard order and repetition count.

## Candidate temporal record

For each observed transition, retain:

- source state;
- target state;
- observation index `t`.

The index is not a third state. It belongs to the history layer.

## Control

Compare histories that induce the same relation:

`0 → 1 → 0`

`0 → 1 → 0 → 1 → 0`

Their structural relation is equal, but their temporal records differ.

## Question for the experiment

Can the temporal record distinguish the two histories without changing the binary state space?

## Interpretation rule

A successful distinction does not prove consciousness, meaning or semantic memory. It establishes only that temporal information is an independent layer from the induced relation.

## Next

Test the smallest temporal annotation (`t`) and then test whether less information than the full index is sufficient.
