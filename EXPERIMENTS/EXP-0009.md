# EXP-0009 — One compact memory, multiple derived views

## Question

Can one compact temporal representation generate the full history, relation, adjacency matrix, and graph edges without separately storing those views?

## Candidate

Use only:

`initial + ordered targets`

From this representation derive:

1. transition history;
2. binary relation;
3. 2×2 adjacency matrix;
4. graph edge set.

## Control

`0 → 1 → 0 → 1 → 0`

Compact memory:

`initial = 0`
`targets = [1,0,1,0]`

Derived relation:

`{(0,1),(1,0)}`

Derived matrix:

`[[0,1],[1,0]]`

## Required invariant

The same compact memory must be sufficient to reconstruct every derived view without storing duplicate copies.

`0 → 0` must remain explicit in all views.

## Boundary

This demonstrates representational derivability for tested contiguous binary histories. It does not establish optimal compression for arbitrary data or prove information-theoretic minimality.
