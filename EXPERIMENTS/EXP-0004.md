# EXP-0004 — Structure versus history

## Question

Can different temporal histories induce the same binary relation, and can repeated history add information that the relation alone does not retain?

## Control pairs

### Pair A — same relation, different history

`0 → 1 → 0`

`1 → 0 → 1`

Both induce `{(0,1),(1,0)}` but their ordered histories differ.

### Pair B — same relation, different repetition depth

`0 → 1 → 0`

`0 → 1 → 0 → 1 → 0`

Both induce `{(0,1),(1,0)}`, while the second contains more temporal observations.

### Pair C — zero preservation

`0 → 0 → 1`

`0 → 0 → 0 → 1`

Both retain `{(0,0),(0,1)}`. The `0→0` self-loop must remain explicit.

## Interpretation

A relation is a structural projection of a history. If two different histories induce the same relation, the relation preserves structure but not all temporal information.

This is an experimental observation about the representation, not a claim about memory or meaning.
